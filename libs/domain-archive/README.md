# Domain Archive

This library stores archived domain models and fixtures needed by archived UI prototypes.

Archive naming should keep historical code readable as English. Prefer `legacy` as a leading descriptor for archived model concepts, such as `legacy-run-state`, `legacy-fixtures`, or `LegacyRunner`, so current code and archived code do not look interchangeable.

Domain work does not have multiple legacy iterations yet. If it becomes necessary, decide how to handle multiple layers of legacy domains and write that structure down here.
