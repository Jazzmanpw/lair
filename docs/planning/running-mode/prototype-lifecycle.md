# Running Mode Prototype Lifecycle

Running Mode prototypes are either active or archived.

Active prototypes are the best current expression of the model, UI, or interaction direction. They are not final implementation, but they are the default foundation for future Lair work until a better prototype supersedes them.

Archived prototypes are preserved as design evidence and historical reference. They may still contain useful ideas, but they are no longer the default source of truth for the current direction. A task can explicitly reopen or compare archived prototypes when older work is relevant.

Archive status is independent of implementation iteration. A prototype from the current implementation iteration can be archived when it was discarded, superseded, or reduced to inputs that have already been carried forward into active prototypes, findings, framing docs, or newer task direction.

Archive library structure is documented in `libs/ui-archive/README.md` and `libs/domain-archive/README.md`.
