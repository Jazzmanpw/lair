# Reminder And Inquiry Prototype Index

## Product Value

During play, the GM needs protection against missing prepared consequences without turning every useful reference into equally urgent permanent content. The same workspace should also make intentionally prepared discovery material easy to consult when players investigate.

## Index Goal

Track the prototype sequence that establishes reminder and inquiry item internals before composing them into lists or placing them in a full Running Mode layout.

Use the [candidate inventory](../shared-surface-candidate-inventory.md) as the evidence and routing record. Use the [shared prototype guidance](../reminder-inquiry-shared-guidance.md) as the common agent-facing reference. Child tasks own their local alternatives and examples.

This file is the human/orchestrator index: it should stay compact, point to the current task order, and avoid carrying common guidance that belongs in the shared reference.

## List Readiness

Begin surface composition only after the item studies provide:

- credible T1 lines for representative and difficult samples;
- plausible T2 treatments;
- observed runtime-state and annotation needs, such as active/inactive state, dismissal/recovery, source staleness, rolled results, or runtime notes, without treating that list as exhaustive;
- negative evidence about content that does not scan well;
- enough density estimates to compose mixed lists without inventing item internals inside the list task.
