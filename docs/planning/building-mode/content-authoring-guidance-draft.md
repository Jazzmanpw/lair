# Building Mode Content Authoring Guidance Draft

This draft collects content-shaping rules discovered while prototyping Running Mode. They belong to Building Mode because authoring should help the GM produce material that remains readable and useful during play.

The document is an accumulator, not a finished authoring UX specification. Future Building Mode work should decide whether each rule becomes validation, a soft warning, an example, or quiet structural guidance.

## Scene Details

Scene details describe only facts the PCs can notice without checks.

They establish the shared physical situation the GM needs to keep in working memory and can communicate immediately. Information that requires Perception, Recall Knowledge, investigation, or another check belongs with the relevant check, trigger, or deeper reference rather than in scene details.

Prefer a short bullet list that can be scanned as one coherent unit. Room shape, dimensions, and passages may move into an optional scene sketch if that direction survives its own prototype.

## Flavor Text

Flavor text is optional player-facing introductory narration.

Keep it to at most five sentences. This is a perceptual budget for reading or paraphrasing an introduction at the table, not merely a display truncation rule.

Flavor text and scene details may overlap in subject because they serve different readers and moments: flavor text introduces the scene to players, while scene details remain the GM's stable factual reference.
